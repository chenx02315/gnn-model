## 具体发现及对执行器的影响

| 命令 | 手册实际说明 | 本实验应如何处理 |
| --- | --- | --- |
| read_faults -merge | 1421页：已存在故障保留优先级较高分类；新故障会加入总体；1420页：merge自动采用n-detection append | 工具合并后分类不是纯F向量检测结果，不能直接当作F独立检测集合 |
| reset_au_faults -reclassify | 2086–2087页：重置特定AU/PU类别并按当前设置重新分类，示例支持跨模式增量ATPG | 它不是清空所有导入检测信用的命令，不能据此声称DS/DR均由新F向量产生 |
| set_fault_mode uncollapsed | 2396页：影响故障列表、计数、覆盖率及报告；代表故障后列等价故障 | 可用于完整集合报告，但不是跨模式物理等价性保持证明 |
| simulate_patterns | 2805页：进行好机仿真；只有存在当前故障列表时才同时进行故障仿真 | 必须在仿真前证明目标故障总体和前态，不能以命令退出0代替故障仿真已发生 |
| simulate_patterns -source external -store_patterns none | 2805–2806页：显式选择外部向量，不写入内部向量集；none也是默认值 | 后续新执行版本优先使用显式参数，禁止新ATPG/随机/BIST来源 |
| report_patterns -external | 1906–1907页：不加开关默认报告内部向量；-external报告已加载外部向量 | 必须显式选择外部报告；否则可能把内部向量0误判为加载失败 |

外部chain-test向量不参与故障覆盖（2805页），因此不能把chain/setup/flush数量混作旧报告的256个test patterns。read_faults默认可能只汇总加载错误（1422页），并且黑盒中的故障可被丢弃（1419页）；退出码正常并不足以证明总体完整。
