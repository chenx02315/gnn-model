# E15：将成本评价对齐“直到首次命中”

## 结论：先纠正评价窗口，不急着重训

E14有5/12组“前3次截断成本”上升，但在同一记录评分策略下，**假设允许继续到首次命中**，这5组以及其余7组的完整首次命中合成成本都下降。风险同样12/12下降。

因此，高成本正例不一定让首次命中更慢。部分表面权衡来自“失败时在第3次停下、不再计费”的评价窗口。E14原NO_JOINT_IMPROVEMENT只是在原风险/截断成本判据下的结果，**不改历史判据或状态**；E15是新的只读数学诊断。

这不是新实验、实际ATPG加速或实际在线继续搜索的证据。

## 用一个具体例子理解

只有两个候选，负例费用1、正例费用100：

- 随机先试一个，预算只允许1次。截断期望成本50.5；若没命中还能继续，完整首次命中期望成本100.5。
- 优先尝试正例，第一次花100就命中。截断成本从50.5升到100，看起来“变贵”；完整首次命中成本从100.5降到100，其实省掉了失败负例的尝试。

正例自己的费用在“保证找到这个唯一正例”的完整搜索中不可避免。截断策略却可能因为根本没试到正例而不支付它，不能单看这个成本判断谁更快找到答案。

## 三个量必须分开

记K=3、N=6，每个任务恰有一个已知正例，费用固定且可加：

1. R_K：前K次未命中的概率。
2. C_K：命中就停，否则第K次截断；E14报告的成本。
3. C_N：保持同一PL评分策略继续到首次正例命中，最多遍历N个候选的假设累计成本。

同一策略满足：
`C_N = C_K + R_K × E[第K次后额外费用 | 前K次未命中]`。

这里的尾部费用随策略改变，不是一个固定常数；没有把每次都收费全部N个候选，也没有排除失败分支。命中动作本身照常计费。

E14现有loss是`.5 R_K + .5 C_K/B_K`，B_K=K×max(cost)。正比例缩放后等价于`C_K + B_K R_K`。**现有loss已有固定失败惩罚**，不是“忘记惩罚失败”。问题是固定惩罚不等于策略相关的完整尾部费用，且“C_K和R_K都必须下降”的科学标准与用户的累计首次命中目标不完全同义。

本n6/K3情形最多剩3个尝试，B_K也可作静态尾部上界；不能直接推广到其他N/K或实际timeout/retry策略。

完整费用还可独立验证为：
`C_N = cost_positive + sum_negative(cost_i × P(i排在positive之前))`，
PL的一正例情况中`P(i在positive之前)=exp(score_i)/(exp(score_i)+exp(score_positive))`。
两个公式在24个初始/最终状态最大差约3.55e-15。完整费用对正例评分的导数为负，所以在**单任务评分空间**提升正例有利于降低完整费用；这不保证共享模型每一步或每个任务都改善。
