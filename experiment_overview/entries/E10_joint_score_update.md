# E10：同一个有限分数变化的联合验证

## 问题与冻结设置

E09 只认证两个各自方向；E10 检查同一个有限变化是否同时使预算内未命中风险不恶化、标准化截断成本下降。正例仍指 ε 近优动作，不是 D95 合格分类头。

mixed/rare 两个 n6 样例、K3、四 seed11/29/47/83。每组64个 pilot 拆为32基线和32梯度，两个独立随机流。候选混合 λ∈{0,.25,.5,.75,1}、步长∈{.05,.1,.2}，共15个候选；只按 pilot 预测选择一个。固定风险预测余量为 pure-risk 下降预测的10%，成本预测必须下降。

8份完整协议、方向、候选、选中候选及分数哈希都先冻结，再调用精确原始全 PL oracle 验证基线与唯一选中候选。Oracle 不用于挑候选、改步长或拒绝后换第二个。

验收统一计算 Δrisk 与 Δnormalized_cost：前者≤1e-12，后者≤-1e-8。两者同时满足才提交 toy 分数状态；否则保持基线。B=K×max_cost 在变化前后不变，命中动作的成本计入。

## 边界与证据

这里只改变合成分数字典，不改变真实模型参数，不使用 Torch、optimizer、checkpoint、真实标签或远端。精确 oracle 是独立计算路径，不是独立电路/家族泛化评价；无新统计 CI 结论。1e-12为实用数值容差，非形式化 IEEE 证明。

这不能证明实际 ATPG wall time 已下降，也不能证明参数空间同一变化已通过。先前 E05/E07 的不确定结果和 E09 各自方向结论不改判。
