# E105：把已有组件接起来，不再重复造执行器

## 目的与当前结果

E104已经解决剩余三条路径的工具导入接受，本轮回到后续采集的数据链。新增一个本地合成薄层，连接原E84计划、E87请求冻结、E86父输出绑定和E83持久生命周期/预算组件；旧组件未修改，没有新增远端访问或真实进程入口。

本地17项专项、83项相关回归均通过，零跳过、零失败、零错误。成功夹具完整遍历两电路78任务/18动作，其中48个模拟Tessent阶段、30个模拟翻译阶段；这些数字是合成协议覆盖，不是实际ATPG调用或模型提升。独立复核结果另存小型manifest。

## 接起来的关键规则

- 每电路固定24个Tessent额度、15个翻译额度；开始前由原E83唯一扣账，外层不再扣一次。失败不退款，不把未知费用记成零。
- 原预算器只理解翻译依赖；外层保留E86的两个真实语义父项。预算字段中的旧名request_sha256明确只是版本化意图摘要，不冒充运行时真实请求摘要。
- 先持久化外层请求意图，再进入原生命周期。成功输出先经过E86的摘要/调用方声明检查，再写外层终态回执，写入确认前不推进绑定器。
- 已知失败、超时或已确认的启动前额度拒绝，停止当前电路，余项未尝试；未知启动/终止、存储或绑定不确定，停止整个包且不恢复。
- setup费用独立记录；合成session从header写入前到最后任务回执后、session自身确认前。不是正式ATPG耗时，不包含关闭成本或证明全部费用。
- 两电路使用相同单调时钟会话和host/boot身份集合，拒绝跨电路重复进程身份；仍是合成身份，不是OS认证。
- 每次操作检查原始绑定与持久记录。快照遇到无法读取或身份不匹配的phase，计数为null并停止，而不是读取一个脱离绑定的budget并报告零。

## 故障覆盖与边界

测试覆盖完整成功链、双父绑定、超时、未知启动、伪造额度拒绝、真实模拟额度拒绝、setup失败、输出摘要错误、终态回执写入失败、重复身份、时钟回退、文件篡改、存储读取失败、错误绑定与创建期间调用方修改输入。临时测试目录自动清理；不读取真实候选、质量或BLIND数据。

回调的synthetic_only/actual_processes字段只是约定，不是进程沙箱。输出authenticated=true仍是调用方声明，不能证明物理产物。4MiB只限制本模块自己的语义回执，不是磁盘配额；旧journal有各自限额，回调外部写入未受此限制。只读回放不能证明历史fsync确认，且不支持恢复writer。
