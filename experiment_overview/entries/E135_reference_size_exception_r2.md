## 实现方式

不修改旧32MiB常规读取器或旧失败证据。新入口取消这个文件的体积上限，但不将整个PDF读入RAM，也不通过大块base64 JSON传输。

远端按最多64KiB分块发送原始二进制；本地直接写入新专属目录内的独占临时文件。开始时先返回实际文件大小与身份，随后完成全文件SHA及前后身份核验；本地再流式复算落盘文件SHA。只有全部校验通过，才发布完整PDF，失败则保留部分文件和原始诊断。

保留512MiB远端采样阈值、60秒时限、一次调用/零重试、非空普通文件/单链接/所有者与路径核验。下载前核对本地磁盘可容纳已声明文件并额外保留2GiB；这是防止写满磁盘，不是把32MiB改成另一个任意文件大小上限。例外在本次成功或首次失败后结束，旧常规规则原样保留。
