# E87：采集不再依赖模型图哈希

日期：2026-10-23。结论：完成无图采集请求到阶段配方的接线；尚未执行真实采集。

## 为什么需要

ATPG 采集只需要电路输入、共同故障集合和运行前请求，不需要先训练模型或提取图。旧 E81 借用了模型特征 freeze，间接要求图 SHA；填假 SHA 会混淆数据身份。

本次新增独立采集 schema，固定 E84 整个计划、一个电路的全部请求、共同故障分母和输入清单 SHA。它不包含图、checkpoint、质量或耗时结果，也不生成模型特征。输入清单 SHA 与分母仍是调用方声明，不能因字段名含 authenticated 就当成已经物理认证。

## 实际接通了什么

E81 只在精确的新 schema 下采用采集校验，原 E80 特征分支保留。E86 绑定器可从无图 freeze 为两个电路各39个槽生成完整 H/M/F 请求和配方；父结果及翻译身份仍逐槽连接。原有派生路径、Tcl、argv 和环境配方未改，也没有创建或部署其未来目录。

此处“配方可编译”不等于“可运行”。真实文件、翻译、持久扣账、进程完成、资源守卫仍未接通；所有配方保持 `execution_ready=false`。
