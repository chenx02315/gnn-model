## 为什么不只数行

两个文件都有一百行，不代表对应的是同一百个故障；即使集合相同，翻译关系也可能把行配错。错误映射会使后续覆盖率看起来正确而实际继承错误。

本次按本地生成器参考规则逐行检查：H/M 原生路径等于 canonical 路径；F 的 `/U数字/` 实例名按 manifest 中统一偏移量变换后等于 canonical。还要求 canonical 和各模式键唯一，各模式 BASIC 文件的故障集合与映射原生集合完全相同。manifest 中的路径、计数、SHA 必须与实际文件一致。
