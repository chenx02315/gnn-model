# E26：同总采样预算下，独立预采样基线能否降低风险梯度噪声

## 执行前目的与公平对照

E25已验证多正例风险公式和正例信号，但736动作/K=10时，每组仍有317–338个负例坐标不在正确正方向。这一轮只检验一个改动：加入由独立预采样估计、主采样前冻结的基线；不换目标、不改费用或特征、不训练模型。

原估计为`dS + S*dlogq`；新估计为`dS + (S-b)*dlogq`。基线b是32条独立预采样的风险均值，不用主样本挑选、不使用解析真值作基线、不对b求导。独立固定b时，`E[dlogq]=0`，应保持完整梯度期望不变；小规模非均匀例必须先验证这一点，不能只看均匀例变好了。

固定[合同](../../contracts/ranking_v6_multi_risk_control_diagnostic_v1.json)：原方法512条主路径，新方法32条预采样+480条主路径，每个方法每例都是512条。确认seed为83/101/137（不同于E25的11/29/47），736动作、K=10、均匀评分、正例数1或6，两个方法共6个配对例、6144条路径。整轮比E25单方法多一倍工作，不能写成整轮预算没增加；保持相同的是每方法预算，不保证运行时间相同。估计器仍有界内存、单进程、无模型或轨迹常驻。

main使用seed，pilot使用seed XOR固定非零常数的另一局部PRNG对象，冻结后再开始main。它实现的是独立采样模型的分流，不是通过种子不同就“实证证明统计独立”。不碰全局RNG，不把此处的pilot预采样与真实数据PILOT家族混淆。
