# E08：输入条件成本范围推导

- 问题：E07 的风险方向已认证，但两项成本投影仍被通用范围撑大；能否从输入条件推导更贴合的合法成本界？
- 方法：固定评分/成本/K/唯一正例，加已冻结的标准化成本基线；从 C=c_positive(1-S_K)+Σ c_negative,t S_t 推导直接导数、提议导数和残差区间。没有 main 观察值、方差或经验极值输入。
- 检查：7 项确定性测试通过，独立复核也实际运行7项并通过；小规模逐轨迹、零成本 oracle、各 K/基线、极端分数/成本、平移/成本尺度/顺序不变与非法输入均覆盖。
- 支持域：成本只支持 0 或 [1e-6,1e9]；标准化基线在 [0,1]。全零成本必须基线0，返回精确零梯度范围、标尺1。
- 开发修复：发现次正规极小正成本可能在旧原始成本计算中下溢，故新 helper 在 exp 前拒绝低于1e-6的正成本。不是一次正式采样失败，旧控制模块未修改。E05/E07 样例成本不受影响。
- 限制：固定±1e-12为实践保护，不是形式化浮点证明；独立 pilot 冻结责任在调用方。这里只发布实现与推导结论，不发布 CI、optimizer 或 TRAIN 许可。
