# E06：风险先验范围推导

- 问题：E05 的稀缺正例风险区间主要被通用范围撑大，能否从固定输入条件推导更贴合的合法范围？
- 方法：仅使用固定评分、K、正例 UID 和已冻结的独立 pilot 基线；用剩余负例权重子集和包络推导生存概率、直接导数与提议 log 导数的范围。没有读取 main 样本、方差或经验最小/最大值。
- 检查：新增6项测试实际通过；n≤7 全负例前缀逐坐标覆盖，各 K、基线0/.5/1、极端评分±20、平移与非法输入等通过。独立数学审查通过。
- 限制：只有单正例风险范围，成本范围未改；端点固定±1e-12保护是实践浮点保护，不是正式 IEEE 浮点误差证明。单独 helper 不发布 CI 或训练许可。
