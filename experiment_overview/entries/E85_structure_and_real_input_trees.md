# E85：补齐电路差异特征与真实采集输入身份

日期：2026-10-23。结论：真实输入核验成功，结构特征实现通过；尚未开始新 ATPG 采集或模型对照，不能据此声称模型提升。

## 为什么做

模型需要知道“这是什么样的电路”，而不只是“打算用多少 H/M”。同时，后续采集必须锁定真实输入，不能仅凭目录存在就开始跑。

本阶段并行完成两件事：实现六个运行前结构描述量；对 aes_core/spi 的六份 TSDB、库和 Tessent 入口做一次有界只读核验。没有读取真实图、checkpoint 或 BLIND，没有提交作业或远端写入。

## 结构对照到底怎么比

六个量为：单元数、连接数的对数，时序单元比例，平均扇出、95% 分位扇出，以及切断进入时序单元的边后的组合深度。它们描述单元图，不是电气引脚扇出或 STA 时序深度。

对照 A/B 都采用 13→32→32→1、1,537 参数和成对相同初始权重。A 输入七个请求特征，屏蔽六个结构槽；B 启用六个结构量。这样避免把“增加电路信息”与“扩大网络容量”混在一起。归一化仅用拟合家族。

四个人工小图已验证实现。真实图仍未认证；旧图构建器的正则引脚/时序分类和自环省略必须先核验。组合环导致深度缺失时不得填零或静默丢电路；A 的零槽是预定消融，不是缺失值插补。

## 修复与边界

初审发现路径检查后再打开目录存在祖先替换窗口。最终实现逐层持有目录 FD，使用 `O_DIRECTORY|O_NOFOLLOW` 和相对 FD 打开文件；Python 3.6 枚举使用固定内核 `/proc/self/fd` 别名。测试后才执行远端观察。并非对抗恶意重命名或挂载变化的完整证明。

默认复核模型额度不足，使用已声明的 gpt-6-sol 回退进行实现与独立复核，未跳过复核。

主机 MemAvailable、磁盘剩余空间只是当时信息，不是资源预约。cgroup 信息部分缺失；实际 ATPG 内存与超时仍为空。读取器自身 256 MiB 上限不能冒充 Tessent 上限。`remote_termination_verified=false` 原样保留，传输成功不扩张为进程树清理证明。
