# E61：A 端 Python 3.6.8，确认存在接口兼容性缺口

日期：2026-10-18。独立的解释器能力观测，不是 E60 数据读取重跑。

## 实际结果

一次严格固定 SSH 观测 exit0，回执确认：Linux、Python `[3,6,8]`，`str.isascii` 不可用，`scandir(fd)` 未声明支持。没有打开项目文件、列出项目目录或执行实际文件系统探针；没有输出环境变量、完整版本字符串、模块路径或异常原文。

这证明 E60 原代码与本次观测到的解释器存在兼容性缺口。原 E60 失败回执没有具体 guard，因此它的实际触发点和读取进度仍记 UNKNOWN，不能改写为“已证明唯一失败原因”。

## 验证和资源

9 项合成测试和独立执行门禁通过后运行一次，零自动重试；相关回归共 808 项，802 执行通过、6 条件跳过、零失败/错误，64.155 秒。针对性测试不与总数重复累加。

资源仍是地址空间上限 512 MiB、CPU 上限 30 秒、单 worker，stdout/stderr 各 16 KiB。SSH 观测耗时 1.116 秒不是 ATPG runtime。没有访问 B、修改远端环境、升级 Python、提交作业或训练。

实际小回执 SHA-256：`60ffa156ea2533deaa2986947b433888aaeff30ca52b73cb076894a36ffb8c1f`。缺少 API 是有效环境观测，不是 E60 目录审计通过。

## 继续进行的修复

在全新 E60-r2 中修复读取器，而不改 A 端环境：ASCII 检查用等价字符范围判断；目录枚举拟通过本进程持有的目录 FD 的固定内核别名进行 lazy 枚举，并核对前后身份。它是明确的、仅对本进程内核句柄的窄例外，不接受外部链接目标，不做真实目录路径/listdir fallback，不声称抵御敌对 mount。

原来的祖先 nofollow、文件单链接/身份检查、512 个目录项、16 个选中文件、字节预算及全部日志/status/submit 正文 no-open 政策保持。新实现、合成测试和独立审查通过前不执行；原 E60 失败及原始文件保留。
