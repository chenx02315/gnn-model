# E29：新风险与完整成本是否正确传到真实模型参数

## 要回答什么

本步不训练。它验证E28的新多正例目标经既有1,345参数MLP传到参数后，仍是正确的导数；并防止把随机估计误差与接线误差混为一谈。

使用同一个六动作、两正例、K=3生成fixture，既有七输入7→32→32→1模型，CPU float64、seed11，没有人工正例评分offset。成本包括首个正例，固定分母60，权重0.5/1。本步不是GraphSAGE，不读取checkpoint。

## 两种证明不能混写

1. **随机向量接线**：只在初始模型处调用一次新control估计器，32条pilot+480条main，共9216名义工作。随后冻结风险/成本/联合评分梯度，对固定线性surrogate做参数有限差分；所有扰动都不重采样。这证明这份向量传递正确，不证明它等于精确期望梯度。
2. **真实非线性目标接线**：另用小规模Decimal80风险参考和完整成本解析梯度。每次参数扰动都重新前向、重新计算完整非线性期望目标，再核对参数导数，不冻结目标冒充链式证明。

每层分别检查风险、成本、联合三条链，每条检查预声明的最大绝对活跃坐标和一个固定全参数方向，共12项FD。固定epsilon1e-6、容差`1e-8 + 1e-5*max(|解析|,|FD|)`，活跃坐标必须大于1e-7；检查ReLU分段不跨界。失败不换seed、坐标、步长或预算。
