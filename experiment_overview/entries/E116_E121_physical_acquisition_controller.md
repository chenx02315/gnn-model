# E116—E121：固定整包实际采集执行器

## 为什么做

不是再训练一次模型，而是补齐可审计的真实 TRAIN ATPG 采集：固定 AES/SPI 两电路共18个动作，48个生成阶段和30次状态翻译。以真实耗时和产物为后续模型诊断提供证据；请求控制、实际 pattern 数、ATE 周期注释、D95 和 wall runtime 始终分开。

## 一次性授权及边界

使用 E111 用户整包答复，不新增训练、B、BLIND、LSF 或历史改写权限。一个实际版本、单 worker、首失败整包停止、零自动重试。512MiB 是 worker+子进程 RSS+swap 采样停止阈值，8GiB 是新 ROOT+初始化 sidecar 目录采样停止阈值，均不是硬容器上限或磁盘配额。仍用 E112 第一次 A 调用启动的原 boot/monotonic 时钟；14小时不得因新脚本、重连或当前阶段重置。

## 实现内容

- E116：初始化前独占落 sidecar；每一任务先扣账/持久 intent，再复制输入或运行；48/30 总预算，setup和clone费用保留事件。观察 metadata 先封存，再写原始日志及独立 ACK；日志失败或结束时钟异常也不丢真实返回状态。每次 Tessent 前重新完整哈希固定 launcher，防止把 E112 的旧观察当新鲜认证。
- E117：七类产物完整稳定回读/摘要；真实 statistics 格式；大 STIL 两遍有界分块处理，不整份载入内存；翻译在同一 worker 内执行，完整核对父 native MTFI、目标 basic 和映射，独占发布后完整回读。小引用 SHA 与 native MTFI SHA 不混用。显式 DS/DI 集合按 canonical 路径并集，EQ 不凭相邻行推断。请求 Pattern_count 不被假定等于或严格封顶实际 pattern 数。
- E118：初始化 sidecar fsync/读回；新目录及 sidecar 一并计费，正常文件增长保守计数，最多1秒缓存仍检查根身份和原截止时间；符号链接、硬链接、替换和未知特殊叶拒绝，只有已核 PVM socket 的 metadata 例外。
- E119：在剩余两份额度内真实读回两电路 H-full driver logs，共55,743B，完整回包75,526B，采样峰值12,095,488B，rc0。历史报告现已8/8，禁止继续扩展扫描。
- E120：从既有本地精确回读构造6组 startup profile；H64 不套 M16。只屏蔽与冻结 Tcl 完整命令/续行完全一致的代码回显；未知告警、真实错误及 invalid path 拼写族仍停止。已见控制/搜索提示按固定相位和完整消息模板逐条保存为结果风险，不称无害或 D95 PASS。AU 增加百分比不是故障比例，不臆断上限100%；使用有限数值策略界，并按原121字节表格精确调整数字对应右边距。M/F 的生成消息规则明确是有限策略推断，不伪称已经观察过其生成。
- E121：一次性部署包动态加载显式来源名单，不复用 synthetic backend 冒充实际进程。环境值只在 A 端父子进程内存之间传递，不输出到 Git/日志/本地终端。先执行3项 Linux 进程自检，成功后才自动进入固定任务；原始传输输出先留存再验收。
