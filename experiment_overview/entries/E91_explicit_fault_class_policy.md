# E91：真实类别的显式、保守继承策略

2026-10-23，实现与独立复核通过；本阶段未新增远端连接或ATPG。

E90已证明实际文件出现点号DI子类、AU子类、EQ和RE，旧暂定翻译核心会拒绝。此次不采用“所有DI开头都算已检测”，而仅添加已观察的DI.CLK、DI.SCAN、DI.SEN、DI.SR四个精确拼写；既有DS、DI及暂定数字子类规则保留。未知DI.UNKNOWN、DI.SCAN.EXTRA和其他未知类别仍拒绝。

AU.PC、AU.TC、EQ、RE可被识别，但不输出为继承检测状态。尤其DS后紧邻EQ也不推断为DS。原参考翻译器本来只携带显式DS/DI条目；此处保留保守子集，不声称EQ真的未检测。可能额外触发ATPG工作，所以配方与费用必须保留策略版本，不能无标记混入历史数据。

翻译清单增加策略V2、未携带类别名单和“不推断EQ/不证明被排除项未检测”标记。目标最低预检测数仅为显式目标初始检测与翻译检测集合的并集下界；不是D95证明、完整等价类计数或Tessent接受证明。

本地12项专项与独立复核通过，包含四个点号子类逐个继承、未知后缀拒绝、EQ邻接不继承以及目标基线EQ不计为显式检测。最终相关回归1,293项中1,287通过、6条件跳过、零失败/错误，41.339秒。后续需用固定真实输入检验新核心，并确认目标工具接受；不能把E90的旧兼容标记false改写为成功。
