# v6：独立 pilot 基线原型

## 当前结论

已继续补齐负例梯度的控制变量实现：独立 pilot 先估计风险/成本均值并冻结，main 使用该常数基线。小规模精确枚举确认，每个 UID 的期望梯度仍等于原始首次命中目标，没有因减去基线而改掉优化目标。

目前证明的是“实现不引入偏差”，尚未证明大候选、非均匀评分下的方差实际下降；不能把原型写好称为训练成功。本次没有运行新的大样例或正式训练。

## 为什么不引入偏差

对负例提议分布 q，梯度观察使用 `直接导数 + (目标 - 冻结基线) × log(q)导数`。条件于独立 pilot，基线是常数，而提议 log 导数的期望为 0，所以减去基线不改变梯度期望。

main 内部样本均值不能替代这个独立冻结基线，也不对基线求导。pilot 与 main 使用不同 SHA-256 phase seed，main RNG 只在基线冻结后创建。

正例的提议 log 导数恒为 0，因此控制变量不改变任何一条轨迹上的正例风险/成本梯度；上一版本得到的正例信号未被破坏。

新增 9 项测试全部执行并通过：合法任意基线与全 PL 精确 oracle 的所有 UID 梯度比较、与旧版逐轨迹对照、独立 pilot/main 手动重放、全部 UID 有限差分、确定性与平移不变、全零成本、先验范围、非法输入先于 RNG 拒绝、n=7 精确枚举。

本轮聚焦回归总计 103 项，0 failure、0 error、11 项既有平台/无 Torch 条件跳过；本次新增的 18 项条件停止/控制变量测试没有跳过。

保持 n≤1024、K≤10、单正例、至少 K 个负例。工作预算同时计入 pilot 和 main，n·K·(pilot+main)≤20,000,000；状态 O(n+K)，不留轨迹。全零成本显式返回零成本/零梯度，归一化标尺用 1，不除以 0。

已推导供未来冻结置信区间使用的保守先验范围：负例风险观察为 [-K-1,K+1]，标准化成本观察为 [-K-2,K+1]；正例分别为 [-K,0]、[-K,1]。这是数学范围，不是观察到的样本最小/最大值，也不是已运行的 CI 实验。

仅新增标准库源码与小型测试/合同/回执，不读取真实标签，不使用 Torch、optimizer、checkpoint、远端主机或 BLIND/LSF/Tessent。没有提高内存或重试次数。旧停止原型和历史结果保持不变。
