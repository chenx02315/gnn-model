# 共享参数提案与区间风险门禁完成

基于 `8316ac4`，本节点状态 `PASS_SYNTHETIC_UPDATE_INTERVAL_ONLY`。只执行固定合成小模型；没有真实标签、图、checkpoint、BLIND、远端、LSF/Tessent 或正式训练。没有应用任何参数更新，不替换既有七列输入或实际模型。

## 从分数梯度走到共享参数

新增线性参考器将每个动作的 score 梯度乘以其合成特征，再按共享参数汇总。风险与费用梯度分开，经固定家族费用尺度归一化后等权汇总。支持最多六个合成家族、每家族七个动作、八个共享参数；这只是可核对 Jacobian 的小空间参考，不是正式模型或大规模反向传播入口。

固定提供最多四个步长，以宏归一化费用梯度产生参数提案；越界拒绝、不裁剪，不选择或应用更新。步长、风险上限及尺度均在评价采样前固定，不能用评价样本调步长。

## 有均值改善不够

区间门禁逐家族要求风险上界不超预声明上限，还要求候选宏归一化费用上界严格低于当前费用下界。若区间太宽、当前风险是否可行仍不确定，或费用区间没有分离，就不接受更新。它不以家族平均风险抵消单家族超限。

`NO_CERTIFIED_UPDATE` 只表示当前证据不足以放行，不证明不存在真实改善。门禁不自行建立统计覆盖；输入半径的有效性必须由上游采样协议证明。真实家族风险阈值、置信要求与费用尺度仍未冻结。

## 固定合成协议和结果

合成家族有两个动作，特征为-1/+1，初始参数0，K1，无单位费用10/1，固定尺度10；步长 `[0.01,0.1,0.5,1.0]`、风险上限0.6。提案来自精确小空间梯度，与评价随机流隔离。所有当前状态及四个提案独立评价，seed11、各预采样256/主采样16384；不同固定case ID经SHA派生随机流。
