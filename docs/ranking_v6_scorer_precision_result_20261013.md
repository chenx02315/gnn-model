## 结论

两件事已经分开验证：现有候选 MLP 的新目标梯度接线正确；736 动作固定均匀样例通过预注册的绝对误差门禁。但后者尚不能证明近优正例的梯度方向可靠，因此本次不放行训练、不宣称跨电路迁移改善。

## 实际完成

- 736 动作、单正例、均匀评分、单位成本、K=10：固定四个 seed，pilot=64、main=2304，无自适应追加。5,896 项比较全部通过，最大置信半径约 0.044996，小于 0.05。
- 统计边界采用经验 Bernstein 不等式及全比较双侧联合校正；方法来源为 [Maurer 与 Pontil，Theorem 4](https://arxiv.org/pdf/0907.3740)。并非把采样误差当成确定性误差。
- 正例风险梯度的四个置信区间均包含 0。绝对精度 PASS 不等于相对精度、下降方向或非均匀模型评分可用。没有通过追加采样改变结论。
- B 端全新目录 `/ssd/cjc/gnn_model_v6_scorer_synthetic_20261013_r1`：8 个小包条目、51,984 bytes 解包量、15,518 bytes 压缩量，源文件逐项 SHA-256 核验。
- Linux 协议门禁：10 项实际执行，0 skip、0 failure、0 error、exit=0，不导入 Torch。独立 prelaunch 复核后只执行一次实际合成 VJP，零自动重试。
- 真实工厂为现有 `runtime_ranking_v3.make_candidate_ranker`，1,345 参数，CPU float64。两类非零参数梯度分别通过有限差分；完整“参数 → scorer → 精确首次命中目标 → 参数梯度”链也通过。

模型权重和已有 `.grad` 均未变化，重复计算确定性通过；没有 optimizer、拟合、checkpoint 或真实标签读取。这里的重复计算是单次验证内部检查，不是第二次容器运行。
