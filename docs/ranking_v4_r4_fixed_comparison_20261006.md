# r4 完整 TRAIN 固定基线比较与后续清单

## 当前结论

第四次运行完整成功，但推荐质量没有通过有效性检验。排除可穷举的 s35932 后，5 个家族 × 3 个 seed 的结果如下。seed 是重复观测，不是独立家族。

| 固定方案 | 近优命中 | 平均 top-10 cycles regret | 平均累计计费 ATPG 秒数 |
|---|---:|---:|---:|
| v4 r4 CandidateMLP | 0/15 | 21.90% | 891.90 |
| v3 CandidateMLP | 0/15 | 18.06% | 904.37 |
| v3 XGBoost | 9/15 | 3.45% | 942.58 |
| 固定启发式 | 3/15 | 8.88% | 940.28 |

v4 耗时较低但没有命中，不能称作加速。非穷举切片没有 v4 与基线共同命中配对，配对耗时指标是不可定义，不填零、不计算加速倍数。全 18 项的 v4 3 次命中全部来自 s35932；该家族相对于 XGBoost 的共同命中成本反而每次高 97.58 秒。

近优阈值固定为该家族候选最小 cycles 的 1.01 倍，K=10。这里优化的是找到 cycles 近优动作所累计的 ATPG wall time，并不把 cycles 和 wall time 当作同一量。`best_cycle_regret_at_10` 使用全部 top-10，不一定只包含首次命中前实际尝试的前缀；不能称为停止时 regret。

这是 TRAIN 内留一家族的离线回放，不是新 ATPG 实测，不是 VALIDATION/BLIND 泛化成绩。XGBoost 暂时是质量参考，不据此选为最终模型，也不新增拟合。

## 本地实现检查：暂未发现评分符号反转

已读取真实 worker → prepare_request → fit_neural → predict_neural → freeze 的调用链：

1. 正例按 `100*cycles <= 101*family_oracle` 判定；留出家族禁止进入构造。
2. 损失为 `softplus(score_negative - score_positive)`，正例分数升高时损失降低。
3. freeze 按分数降序排列，方向与损失一致。
4. normalizer 只在拟合动作上估计，再用于留出动作。
5. 模型实际消费七个候选特征，没有 runtime/cycles outcome 输入；r4 是 CandidateMLP，没有图编码器。

以上是代码和既有测试证据，不是拟合质量证明。仅凭这些检查不能证明正例可分、训练已收敛或尺度迁移可靠。`targets` 虽被准备，但此神经适配器实际优化的是 pairwise loss，不能误称同时做了 regret 回归。

已有 `ranking_v3_train_feature_diagnostic_20261005.json` 已独立检查 1706 个 TRAIN 动作、14 个近优动作：六家族无完全相同的候选特征向量或冲突 cycles 碰撞。这个节点不重复做。无精确碰撞不等于正负可分；大部分家族内变化仍集中在 scheme 与 H/M 设置，common-fault 特征家族内恒定。本次同时核对 r4 release 中 13 个执行源码 SHA，本地全部一致。

不立即增电路，也不宣称无需增电路。先区分实现错误、训练目标失配、特征缺少信息和家族覆盖不足；如证据指向最后两项，再论证补充独立家族的数量与测量成本。禁止通过放宽 ε、增加 K、挑 seed 或去掉失败家族让已有成绩“过关”。

下一步诊断若需要未导出的 TRAIN request / freeze / loss 轨迹，先查是否已有封存产物；没有的轨迹不能假装从汇总还原，更不能在一次拟合授权之外自动重跑。
