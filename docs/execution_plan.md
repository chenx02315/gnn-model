# 执行阶段与硬门禁

1. **P0 合同冻结**：D95、候选空间、时间终点、家族划分、K/epsilon、失败与统计规则。
2. **P1 Attempt 清单**：恢复 wall/user/system time、环境、重试、日志 SHA-256；不按最快记录去重。
3. **P2 候选连接**：将候选唯一连接到 H/M/F attempts，重算 cycles 与搜索成本。
4. **P3 可比性审计**：主机、缓存、许可证、队列和特征时间可得性。
5. **P4 离线回放**：无未来信息的原顺序、随机、启发式和强模型基线。
6. **P5 模型开发**：D95、f_min/ATE cycles、log-wall-time 三任务与 cost-aware Top-k。
7. **P6 b20/b21 前瞻小试验**：同环境随机交织，计入推理、回退和失败成本。
8. **P7 家族隔离盲测**：三 seed，冻结后只测试一次。
9. **P8 论文产物**：主结果、时间分解、失败表、消融与复现包。

P1–P5 未通过前不启动新的全网格 Tessent 作业；P6 未通过前不进入正式盲测。
