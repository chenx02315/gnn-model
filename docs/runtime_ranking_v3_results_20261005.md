# v3 已跑完：排序有进展，ATPG 加速尚未成立

## 当前结论

六 TRAIN 家族 × 三固定 seed × 四方法共72份结果已完成，退出码0，独立重算审核通过。XGBoost 比启发式更容易命中近优组合，但没有证据证明普遍降低首次命中前的累计 ATPG 时间。GraphSAGE 本次没有显示优势，不能为了毕业论文把负结果包装成成功。

## 目标没有变化

压缩模式固定为 H64/M16/F4；正式动作均 D95 安全。模型要推荐“先试哪些组合”，尽快找到 cycles 距该电路最优值不超过1%的组合，减少为找到它而花的累计真实 ATPG wall time。cycles 是推荐质量约束，wall time 是搜索成本，两者不能替代。

四方法均使用固定前十预算。命中时累计成本算到首次命中；没有命中就算十次尝试，但不能将失败时的低成本当作加速。最佳前十 regret 是离线观察前十候选的结果，不是提前停止时已知道的结果。

## 看家族，而不是只看总体均值

s35932只有十个动作，前十必然穷举命中。剔除它后，XGBoost为9/15、启发式3/15、MLP和GraphSAGE均0/15。XGBoost改善主要来自 aes_core 与 spi，s13207和s15850仍全部未命中。

在非穷举家族，XGBoost平均累计成本约942.6秒，启发式约940.3秒；同时命中的s38417每个seed中XGBoost多花约227.885秒。不能用包含s35932的整体成本平均数掩盖这个反例。三seed的XGBoost排序相同，不能当作三个独立家族样本计算置信度。

## 排序失败不是动作编码碰撞

现有1706动作在各自家族内七维特征唯一，没有同特征不同cycles的动作冲突。共14个1%近优动作，各家族仅1–6个。scheme和H/M限制提供候选间变化，graph/common-fault输入在家族内恒定；恒定上下文可能帮助跨家族建模，但不能单独区分同家族动作。这不证明图模型无用，也不支持直接增加电路后盲目重训。

## 下一节点及边界

下一版设计先解决候选排序失效，再冻结有质量约束的成本感知策略；不把未经校准的排序分数除以预测耗时。所有新策略必须定义拟合标签、跨家族划分、固定预算、失败成本、冻结顺序与公平基线，先用合成测试证明语义。

本轮已授权的诊断、代码、测试、独立审查、版本同步持续衔接；不因完成一个小步骤等待“继续”。新真实训练、VALIDATION或BLIND、额外电路/ATPG仍须满足对应独立release，不能从“不要停”推导出跨越封存权限。
