# V6 训练目标与公平对照门禁草案

状态：`DRAFT_NOT_RELEASED_FOR_TRAINING`。依据已封存的 TRAIN 诊断（提交 `b2bc3e7`），本节点仅实现合成小空间梯度校验器并细化合同。不读真实候选顺序、模型预测、checkpoint、BLIND 或原始图，不执行训练或远端任务。

## 本次要解决什么

例如先试两个未命中动作再命中，即使最终 Hit@10 相同，也应比直接命中承担更多费用。把排序分数变成无放回的顺序分布后，可以分别求未命中概率与截至首次命中/K 截断的费用期望；两项对分数的梯度是未来训练目标的校验依据。不能因为一条全失败序列便宜就把它当优胜者。

新合成校验器枚举最多七个动作的 Plackett–Luce 顺序，温度固定为 1，最多尝试十个动作，分数绝对值不超过 20，合成费用不超过 10^9。分数不是校准的动作成功概率。输出风险和费用及其各自梯度，不提供标量加权 loss、optimizer 或训练入口。七动作枚举不是正式 1706 候选空间的可扩展估计器。

## 未命中和费用规则

- 命中动作自身与此前已尝试动作都计费；首次命中即停止。
- 未命中收取最多 K 个实际尝试动作的费用，名单不足 K 不补动作。不能删去未命中样本后只比较成功费用。
- 风险和费用分开报告；不能用降低命中率换取低费用。风险约束的优化算法与容差仍未冻结，不能把字典序评价器误称为可微训练 loss。
- 此处是历史静态费用代理，不是 prefix/cache/session 下的在线增量 wall time。所有实际提速结论仍阻断。

## 公平对照的预备边界

优先只改变目标轴，不同时改变七列特征、scorer、normalizer、划分、三 seed、K=10 或整数 epsilon=101/100。不得根据 held-out 标签调整阈值、选 seed 或选择目标。所有正式模型保持相同容量、拟合标签权限、资源上限和预算。

| 对照 | 要回答的问题 | 不能据此声称 |
| --- | --- | --- |
| 旧 any-hit@10 目标 | 原目标是否忽略首次命中位置/费用 | 它已优化在线累计耗时 |
| 首次命中风险与费用目标 | 改目标是否改善排序与静态费用代理 | 已有可扩展训练器或真实提速 |
| 连续 cycles 排名目标 | 密集监督能否缓解只有 14 个正例的问题 | cycles 等同 runtime |

费用升序与确定性无放回随机顺序可作为无学习参照，但也必须报告 miss，不能仅凭费用低宣布胜出。各基线的确切 tie 规则、随机流、优化预算和实现还需冻结；不能在看完新结果后补选有利基线。

六家族分别报告每个 seed 的 Hit@10、首次正例位置、截断费用与 miss；六家族等权汇总，不按候选数池化。另列五个非保证命中家族的结果；s35932 的十候选保证不能冒充学习改善。费用原始秒与预定义的家族内归一化应并列保留，归一化分母及选择只能由拟合权限内信息确定，不能用 held-out 最优费用选标尺。

## 连续实施顺序与阻断点

1. 合成精确梯度对有限差分、分数平移、K 截断和全负例检查通过，并独立复核。只证明小空间数学实现。
2. 另行设计可扩展梯度估计器：采样数、方差控制、随机流、风险约束优化方式、macro 聚合、数值稳定和内存界必须明确。不得直接对正式候选枚举所有排列。
3. 实现该估计器的合成无偏性/误差、确定性、泄漏与内存测试；冻结 trainer 接线和全部公平基线。
4. 预注册命中非退化与费用改善判定，报告所有 seed。当前诊断不足以合理选择改善幅度和统计容差，故这些数值尚未冻结。
5. 全部代码/环境门禁和独立复核通过，再依据明确的正式训练授权放行。当前草案不签发训练许可，不沿用旧 v5 的次数授权。

始终保持单 worker、1 GiB RSS、8 GiB 地址空间、零自动重试。真实在线目标还需解决未知家族 oracle 下的停止判据和顺序依赖成本证据，不能由离线近优标签替代部署时停止条件。本节点不得解封 BLIND、LSF/Tessent 或扩充电路。

## 下一实现节点：流式采样估计器（尚未实现）

具体方向已收敛到无放回 PL 采样，而不是直接枚举大网格。每条合成轨迹执行至首次命中或 K，累积所选动作 one-hot 减剩余动作 softmax 的 score-function 向量 G。分别平均 `(miss-b_r)*G` 和 `(cost-b_c)*G` 得到两组梯度，不合并风险和费用。

两个 baseline 必须由独立 pilot 随机流产生并冻结；主样本不回流到 baseline，不求 baseline 导数。用包含当前样本的均值中心化可能引入偏差，不能当作等价替换。费用可除以合成域内固定正上界 `min(K,n)*max(cost)` 做数值缩放，再乘回，不能更换目标或从 held-out 标签选择标尺。

下一合同需要先注册固定合成 case 清单、pilot/main 独立 seed 派生、样本预算、总计算量上限与误差判定。建议限定 n<=256、K<=10，流式仅保留 O(n) 统计量、不保存轨迹。逐 case/seed 输出风险、归一化费用及全部梯度，不能选最佳 seed。误差界须对全部比较做多重比较控制，且单设精度门：误差落在很宽的区间不算通过；预算内界宽不足则 `INCONCLUSIVE_PRECISION`，不换 seed 或追加次数。本段是待实现路线，不是已执行的 Monte Carlo 验证或正式训练采样配置。
