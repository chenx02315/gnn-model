# v6：稀缺近优正例的解析停止原型

## 先说结论

已补上一个实质缺口：在固定 736 候选、单近优正例的均匀样例中，不再依靠偶然抽中正例才能获得梯度。四个 seed 的正例风险梯度均为 -0.013485006866910882，与解析真值的绝对误差约 1.2143e-17。

这是合成样例的数值与接线前置证据，不是一次新训练，更不是 ATPG wall time 已经下降。这里的“正例”指 ε 近优动作，不是 D95 合格动作；D95 安全边界未改变。

## 方法与数学检查

仅抽取负例的 Plackett–Luce 顺序。每一步根据剩余负例总权重与正例权重，解析累计“尚未命中”的概率，而不是抽一次命中/未命中的硬结果。正例尝试本身的成本也计入。

设第 t 步剩余负例总权重为 A_t，唯一正例权重为 P；r_t=A_t/(A_t+P)，S_t 为前 t 步 r 的乘积。给定负例提议顺序的风险贡献为 S_K，成本贡献为 c_positive(1-S_K)+Σ_t c_negative,t S_t。对提议分布 q 求期望后，等于原始全候选过程的首次命中目标。

分数会改变负例提议分布，所以梯度必须同时包含直接导数与 F·∇log(q)。省掉第二项会使负例梯度有偏。原型明确保留了它。此等式是提议前缀重加权的推导，不声称是对原始全排序简单条件化后的 Rao–Blackwell 估计，也不声称所有坐标都必然降方差。

单正例的风险梯度观察为 -S_K·Σ_t P/(A_t+P)，在有限分数与 K≥1 时严格为负。均匀负例权重下，A_t 只取决于步数，因此这个正例坐标与抽到的负例顺序无关；这是本固定样例信号稳定的原因。

## 已实际验证

- 新增 9 项测试全通过：非均匀评分/不同成本下，与旧全候选精确枚举比较风险、成本及每个 UID 的梯度；全 UID 中心有限差分；平移不变与梯度和为零；n=7 极端分数；命中成本；零成本；提议导数；非法输入先于 RNG 拒绝；n=1024 单样本资源烟测。
- 固定大样例诊断只运行一次：736 动作、K=10、UID17 为正例、四个 seed 各 32 样本，总名义工作量 942,080。执行前冻结合同与源码，经独立只读 prelaunch 复核；没有追加采样或自动重试。
- 四个 seed 的正例风险梯度均严格为负，与解析真值误差均约 1.2143e-17，小于冻结容差 1e-12。
- 聚焦回归总计 94 项，11 项为已有 Windows/Linux 或无 Torch 环境的明确跳过，0 failure、0 error。本次新增测试没有跳过。

## 限制与资源

新原型只支持一个正例、至少 K 个负例、n≤1024、K≤10；分数绝对值≤20，成本在 [0,1e9]，n·K·samples≤20,000,000。状态存储 O(n+K)，不保留轨迹。工作量是名义上界计数，不是 CPU 指令数或峰值内存实测。

本次为本地标准库验证，未启动 B 容器、Torch、optimizer、训练、BLIND、LSF/Tessent 或真实标签读取。既有已验证 scorer 与历史目录均未修改。上一轮 B 容器的 1 GiB 上限不被本次扩大。

本次没有新的置信区间结论。负例坐标精度、非均匀评分下的方差优势、多正例支持、模型参数更新后的风险/成本改善都尚未获证。四个正例坐标一致，不代表整个梯度向量一致；四个完整风险梯度摘要实际不同。

## 下一条连续任务链

1. 在新的原型版本中加入独立冻结基线的提议导数控制变量；先重新推导无偏性和先验观察范围，保留本版本不变。
2. 小规模精确 oracle 检查全部梯度后，冻结非均匀评分、不同成本及稀缺正例的精度合同；不能只看正例或只挑最好的 seed。
3. 固定预算下验证全部相关方向/成对风险与成本变化的置信界；若不充分，报告不确定，不自动追加采样或重跑。
4. 数值门禁通过后才连接受控参数更新与既有 scorer。独立复核仍不等于正式 TRAIN/BLIND 的自动放行。

最终成功标准仍是家族隔离实验中，找到 ε 近优 D95 安全组合前的累计 Tessent ATPG wall time 降低，并与 ATE cycles 分开汇报。
