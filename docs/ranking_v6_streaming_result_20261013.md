# 流式首次命中估计器：合成门禁完成

2026-10-13，基于 `2e18f90` 完成流式估计器及独立复核。状态为 `PASS_SYNTHETIC_ESTIMATOR_ONLY`，不是 trainer 或正式训练许可。本节点未读取真实标签、BLIND、图原文或 checkpoint，未执行远端、训练、LSF/Tessent 或在线费用重放。

## 已实现

按 Plackett–Luce 分布无放回采样，首次命中或 K 截断停止，包含命中动作费用。风险与费用各有一组 score-function 梯度，不随意合为一个标量。baseline 只来自独立的合成预采样随机流，在主采样前冻结；此处 pilot 不是受保护的 PILOT 数据角色。

UID 固定排序，SHA-256 派生两条局部随机流，不改变全局 RNG。逐样本流式累计，工作内存 O(n)，不保存轨迹。限制 n<=256、K<=10、分数绝对值<=20、费用介于 10^-6 和 10^9，阶段样本数<=65536，工作量上界 2000 万；超界在 RNG 创建前拒绝。该域尚不能覆盖 SPI 的 736 个正式动作，不能直接连接正式数据训练。

## 先注册，再验证

`contracts/ranking_v6_streaming_synthetic_gate_v1.json` 在执行前固定两组小空间样例、四个 seed `[11,29,47,83]`、每次预采样256和主采样16384、全部比较的总错误概率0.01、共64项比较与归一化半径上限0.10。Hoeffding 双侧界加 union bound 覆盖全部比较，不挑 seed；同时要求误差在界内和界宽足够小。预算不足则不确定，不增加次数。

实际门禁一次运行，exit0，全部64项通过。最大归一化绝对误差 `0.006385883641895407`，最大界半径 `0.06795420264546924`。这些是固定合成样例上的一致性证据，不是对所有输入无偏性的经验证明；独立数学审计另检查停时轨迹与控制变量期望。

256动作内存冒烟：预采样64、主采样512、K10，Python traced allocations 峰值75,690字节，低于预注册8MiB。这不是进程RSS，也不是硬内存限制或整个训练的内存证明。原正式资源策略仍是单worker、RSS1GiB、AS8GiB、零自动重试，没有放宽。

相关focused测试41项，1项Windows能力跳过，零失败/错误；没有在本节点重新运行全仓库测试。独立复核另枚举停时轨迹，对照完整排列 oracle，检查风险/费用均值及梯度、独立baseline不改变期望和无I/O执行。

回执保存全部64项误差及界、源SHA、预注册SHA、次数和退出码：`data/manifests/ranking_v6_streaming_validation_20261013_r1.json`。它是捕获 stdout 的归一化JSON，不冒充另存的原始进程日志。
